# Dev Dhanush Portfolio

## Run locally
Open `index.html` in a browser. No build tools or login are needed.

## Host free on GitHub Pages
1. Create a GitHub repository.
2. Upload every file and the `assets` folder from this ZIP.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to publish the site.

## Music autoplay note
The supplied `assets/Suzume.mp3` is included. The site attempts autoplay, but browsers often block audio until a visitor interacts with the page. Use the floating music player’s ▶ button if it does not start automatically.

## Add your projects
Edit the project cards in `index.html` (search for `PROJECT_01`) and update the project list in `script.js` so the project count stays accurate. Replace the example showcase cards/links with your real project details.

## Customize
- Theme toggle: top-right ☼ / ☾ button; preference is saved in the browser.
- Colors and responsive styling: `style.css`
- Links and text: `index.html`
- Interactions: `script.js`
